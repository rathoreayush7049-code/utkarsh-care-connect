# Website Goal

The website should help patients:

* Book laboratory tests online.
* Request home sample collection.
* Contact the laboratory via Phone or WhatsApp.
* View available diagnostic services.
* Locate the laboratory on Google Maps.
* Enquire about health packages.
* Download or request laboratory reports.
